# Security policy

Firebase Editor Pro handles Firebase service-account keys, which give admin access to a project. Please report
vulnerabilities privately through GitHub: **Security > Report a vulnerability** on this repository. Do not open a
public issue, and never paste a `key.json`, a private key or an access token anywhere in an issue or pull request.

If you ever exposed a key, revoke it in the Firebase console (Project settings > Service accounts > manage keys) and
create a new one.

Security fixes are released for the latest version only.
